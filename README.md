# 观象 · 大六壬

一个可复核的中文大六壬问事工具。浏览器根据真实时间计算四课三传，展示已核古籍摘句与扫描原页；用户可用自己的 DeepSeek 账户生成针对当前问题的解释。

网站：[观象](https://999888666jiang-dev.github.io/daliuren/)。当前工作区采用 **GitHub Pages 静态网页 + 浏览器直连 `deepseek-flash`**。真实模型调用、各版本测试结果与最新发布状态见[验收记录](docs/validation.md)。

## 功能与边界

- 默认正时；报数活时用 1—12 映射虚拟占时，真实日干支、月将、月建及昼夜保持不变。同辰再问提供继续正时、改用活时、沿用本盘三种选择。
- 高级本盘续问不调用排盘函数，原天地盘、四课三传、天将与课号不变，问题与年命分别记录，不继承上一问的 AI 解读。
- 一事不二占：检查本机相同问题与已经登记的现实变化。不同新事可继续问；原事情须记录实际新变化。文字检查不能识别所有改写，也不跨设备同步。
- 无需密钥即可查看原始课盘、问题的本地理解与已核原典；AI 根据具体问题作取用、逐项释义和综合推演，每段关联盘值与原句。
- 公历 2000—2100 年、北京时间输入、真太阳时及标准时对照；经度、均时差和跨日处理。
- 月将加时、十干寄宫、四课、九宗门、三传、十二天将、旬空、六亲及推导记录。问题文字不参与排盘运算。
- 古课手工复核、本命/行年地支可选输入；未提供的信息保持缺失。
- 已核原文、影像对照和盘面条件匹配；百法 100 条题名索引逐项标明校勘状态。
- 事项默认“自动识别”，也可手动选类。AI 先理解问题，必要时澄清一轮、最多两个问题，再据原课解读；补充回答不更换起课时间。
- 一次解读流程最多两次模型请求，不自动重试。沿原盘更新解读时先生成草稿，成功后保存完整新版本；失败或取消保留旧答案和原引用。
- 手机布局、按报告 ID 的哈希深链接、本机最近 30 份自动记录、JSON 导出和打印；新报告使用 v3 格式，兼容读取 v1/v2 记录。语义理解、引文与推演按版本一起保存。

排盘、条件检查和资料查询在浏览器运行。AI 通过 DeepSeek 官方接口调用，不需要 Cloudflare 账户、邀请码或应用数据库，也没有全站每日调用配额。每位使用者的调用消耗其填写密钥所属的模型账户额度。

文献真实和软件遵循冻结取法，不等于证明预测可靠。传统判断的可用条款仍有限；排盘口诀不能单独推出事件吉凶，未实现的条件会明确保留。

## 本地运行与测试

推荐 Node.js 24，与 GitHub Actions 一致。

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173/daliuren/`。

```sh
npm test
npm run build
npx playwright install chromium firefox webkit
npm run test:e2e
```

单元测试与浏览器测试使用隔离的模拟模型响应，不需要真实密钥，也不会产生模型费用。通过这些测试不等于完成真实模型、跨域策略或生产网址验收。

## 文献与核验范围

本地归档原件登记在 `library/source-manifest.json`，公开必要原页与核字范围登记在 `library/verified-pages.json`；新增基础断课来源与范围见 [V3 解读说明](docs/reading-v3.md) 和 [来源记录](docs/sources.md)。原件、页面和摘句不能相互替代。26 条固定古课中，23 条有扫描核验、2 条仍为转录待核、1 条为独立手算；九宗门各有至少一个扫描支持的独立预期课。

## 发布、费用与密钥

公开仓库可使用 GitHub Free 的 Pages 静态托管；**免费托管不包含 DeepSeek 模型费用**。模型可用额度、余额和计费以使用者账户及官方规则为准，网站不承诺免费模型额度。[GitHub Pages 说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)、[DeepSeek 模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)。

在网页的密钥面板填写后可临时使用；只有点击“保存到此设备”才持久保存，之后可更新或清除。保存使用浏览器 `localStorage`，同源脚本可读取，**它不是加密保险库**。请只在自己的设备保存。密钥用于发送给 DeepSeek 官方接口的授权头，不作为报告字段保存或导出。

不要将模型密钥写入源码、`VITE_*` 环境变量、构建产物或 GitHub Actions Secret。静态部署不需要模型密钥；使用者在网页运行时输入。GitHub Actions 只运行测试、构建和模拟上游浏览器检查，再发布 `dist/`。详细步骤见[部署说明](docs/deployment.md)。

## 素材与依赖

仪盘与界面图形为可交互 SVG；书房背景由本项目使用内置图像生成工具制作。城市数据为 GeoNames 城市中心参考坐标，遵循其[署名许可](https://www.geonames.org/export/)，不表示用户精确位置。依赖版本由 `package-lock.json` 固定。
