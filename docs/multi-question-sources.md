# 同一时辰多事：文献核查与产品约定

核查日期：2026-09-23。本文是同辰多事功能的来源说明与实现建议，不是对占卜预测有效性的证明。排盘可以按一套公开规则复现，事件是否发生仍须现实证据；“解读真实”应指不伪造问题背景、盘面、古文和准确率，不是承诺预言成真。

本轮阅读范围为现有 `docs/` 说明、`library/` 来源与核验记录、`src/data/` 引文及百法索引、`src/core/` 排盘代码。没有声称逐页读完资料库的七个完整古籍扫描。新增外部扫描只用来核对下列指定段落，没有自动升级现有引文库或增加自动占断规则。

## 一、应当采用的整体方案

默认正时；不同新问题可以主动选择“报数活时”，或者从已有结果选择“本盘续问”。将**问题记录**与**课盘结构**分开：一个课盘可以关联多个不同问题，而每个问题有独立的事项、背景、年命上下文、解读、依据和复盘记录。传统次客移时暂作研究说明，不提供未经版本核对的自动移时按钮。

这能让同一时辰的多个问题得到分别整理和有依据的分析，却不能保证每件事必定出现不同三传、不同吉凶或独立预测结果。不得为了“看起来不同”随机改三传、把问题文字散列成新盘，或在后台重复抽数直到出现新结果。

| 入口         | 实际行为                                                                         | 必須明示的性质                                                                 |
| ------------ | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 正时起课     | 以真实瞬间、所选标准时或太阳时规则计算日辰和占时，真实交中气定月将               | 默认方式；同样结构参数会得到同盘                                               |
| 报数活时     | 用户报 1—12，按子至亥映射为虚拟占时；真实日干支、月将、月建保留                  | 本网站采用的备选操作约定；尚未查得足以证明这套数字界面为某部古籍原法的直接证据 |
| 本盘续问     | 复用原盘、原时间、原三传和原天将；新建问题与阅读记录，可更新用户提供的年命上下文 | 同盘取类的产品功能；不能声称它是“古籍次客法”的唯一定义                         |
| 古籍次客移时 | 展示原典中存在多个加临版本的研究说明                                             | 本轮不固化未经完整校勘的移时／换将算法                                         |

## 二、本轮可以复核的一手文本

### 1. 正时与四课的基础

《虎钤经》“六壬传课第一百二十八”载：“先以月將加正時。”下文说明以日干、日支及各自上神构成四课。[识典古籍所载原典正文](https://www.shidianguji.com/zh/book/SK1391/chapter/1jurpcu27bi8r)本轮已联网读取。它支持正时加临与按日辰取课，不支持“换一个问题就必须换一套日月干支”。该网页仍是电子整理文本，不把它写成此次已经逐字核过的宋刊本影像。

另以现有[《六壬大全》卷一扫描](https://commons.wikimedia.org/wiki/File:CADAL06054168_六壬大全·卷一.djvu)第11—15页的已核寄宫、九宗门摘句维持现有排盘配置，具体字句和版本边界沿用 `docs/sources.md`。

### 2. 次客的确存在多种古代方案

本轮实际下载并用 Poppler 渲染后目视核对了《正学堂杂著》第18册所收《景祐六壬神定经纂》，文件号 `NLC892-411999030028-142313`，共25个PDF页。扫描封面明确是“神定经纂”，不能偷换成宋代原刊全本；PDF第2页题及宋杨惟德原书。文件有中华古籍资源库水印，下载来自 Wikimedia 镜像，本轮没有进一步完成其版本年代、纂者和馆藏目录的版本学考证。

[可直接打开的完整扫描](https://upload.wikimedia.org/wikipedia/commons/a/ad/NLC892-411999030028-142313_%E6%AD%A3%E5%AD%B8%E5%A0%82%E9%9B%9C%E8%91%97_%E7%AC%AC18%E5%86%8A.pdf#page=12)。2026-09-23下载实测：4,885,986字节；SHA-256：`f089b7e5bef7e159903e6680a85d27fa3b5408f8b668594d046c4049095f84db`。本轮只链接原件，研究缓存没有作为新素材加入网站公开目录。

核对范围：

- PDF第9页左幅“释用式三十一”，有转月将加正时并视日辰上下阴阳立四课的文字。
- PDF第12页右幅“释次客三十三”，并列阴阳将前五后三的说法，以及第一客月将加正时、第二客月建加太岁、第三客太岁加月建等另一路法。后文还涉及本命、行年。
- PDF第12页左幅“释次筹三十四”，另按阴阳将、次筹及不同上神三传来分三事。
- PDF第12页左幅末至第13页右幅首“释行年三十五”，载男一岁从丙寅顺行、女一岁从壬申逆行及十年例。

从这些实际可见的异法，可以得出“次客不是只有一套统一的移时口诀”。不能仅凭“前三后三”这种概括就固定实现第二客加三、第三客减三；原文的前后、阴阳、加临对象和计数基点必须一起解释。也不能把古书里的玄女、灵辖经等引称当成已经另外找到并核过的独立原本。

本扫描能证明存在次客异法，但不能证明“所有后世壬家都反对换将”“古人一开始绝不用年命”“后来普遍用年命彻底代替次客”这些历史概括。本轮不作这些断言。

### 3. 类神与问题相关性

本地 `public/sources/daquan-v9-p9.jpg` 本轮重新目视核查了[《六壬大全》CADAL卷九](https://commons.wikimedia.org/wiki/File:CADAL06054175_六壬大全·卷九.djvu)目录第97、98题名：“所筮不入仍憑類”“非占現類勿言之”。它们足以作为阅读方向的题名线索，**只核题名，不等于核完正文与条件**，因此不因本次研究将这两条升级为自动断法。

现有库的已核第31条上下文还涉及年命填实例，说明年命确属传统解读语境中的变量；但现有程序没有完整实现填实判断，不能以新填了本命、行年就自动宣布填空成立或事情必成。

“考试只看官鬼”“找人一律看玄武”过于机械，不宜写成古籍统一规则。学业、任职、文书考试、寻找失联者和寻找疑似被盗物品需要分清；实际取类应写明依据，证据不足时说明未覆盖，不能从一个类神名称推断录用、失踪原因、位置、疾病或特定人的动机。

### 4. 重复占问的文献边界

通行《周易·蒙》有“初筮告，再三瀆，瀆則不告”。本轮读取的是[维基文库原典转录](https://zh.wikisource.org/wiki/周易/蒙)，不是新核古刻原页。可以说明这是传统上慎待反复占问的一条背景材料，不可据此声称它规定了现代软件的去重算法、封禁时长、跨设备限制或所有情形绝不能再问。

在本项目中，“同一事项没有现实新变化，不重复起课”作为明确的产品约定执行；同一问题的补充材料应进入原问题记录。发生真实新变化后可以记录变化并关联原问题，形成后续问题。不要以“重复问就一定失准／招灾”恐吓用户。

## 三、须纠正或保留不确定性的说法

| 原需求中的说法                 | 核查结论及网站用语                                                                                                         |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| 同一天同一个时辰，月将一定固定 | 通常固定，但时辰内恰逢中气可换月将；接近日界、标准时／太阳时边界也须谨慎。本项目已有交中气逻辑，应按实际结构参数判断同盘。 |
| 报 1—12 是“正宗古法活时”       | 本轮没有查得足以作该定性的直接原典；保留功能，写“报数活时：本站采用的备选方式”。不能以未查到断言古代绝无类似方法。         |
| 报数要保留日辰、月将           | 作为本产品可检验的规则固定；报数只提供虚拟占时，不重写真实历法。不能将这条项目约定伪装为本轮核出的古籍原句。               |
| 次客法就是原盘不动             | 可做“本盘续问”，但古籍所称次客还包括不同加临法，不能把名称完全等同。                                                       |
| 每个新问题都应有不同结果       | 不能保证。不同占时仍可能得到部分相同三传；同盘按不同事情分析可以有不同关注点，但不应制造相互矛盾的盘面事实。               |
| 报三个数字一定属于小六壬       | 本站不采用任意替换日、月、时的方法。仅凭数字个数不足以完成术数史归类，不作笼统身份断言。                                   |
| 子时人人心绪散乱，应避免起课   | 没有在本轮核对原典中落实这种普遍说法。可提醒核准23:00换日口径、疲倦时休息；不标作古籍禁令，不禁用整个子时。                |
| 末传的固有能量决定两件事       | “能量”没有本项目可验证的物理定义。可说同盘的结构信息相同，不能由末传一项替代完整判断。                                     |

## 四、实现必须守住的边界

1. **先计算真实历法，再附加虚拟占时。** 原始北京时间／真实UTC、所选时钟、真实时支、日干支、中气、月将、月建均保留；1—12只映射为 `子丑寅卯辰巳午未申酉戌亥`。报数为子不代表真实时间变成23:00，不能触发换日或重新查月将。
2. **明示昼夜口径。** 现有已核《御定六壬直指》摘句以“正时”划卯至申为昼、酉至寅为夜。建议本次备选活时沿用真实时钟的昼夜贵人，虚拟时支只供月将加临；这仍是本项目对备选模式的明确采用方案，不冒称所有活时流派无争议。若选择别的昼夜口径，必须在模式说明及报告中单独标示。
3. **同盘检测使用结构参数。** 比较日干支、月将、用于加临的时支、昼夜贵人配置及规则版本。仅比较日期与时辰段会漏掉中气更替；仅比较三传会把其他部分不同的盘误判相同。问题和年命不是重排基础盘的理由。
4. **保留可追溯性。** 报数报告保存真实时间、数值、虚拟时支、模式和采用口径；续问保存原盘ID与来源问题，不能显示新问题输入时刻是原盘起课时刻。新问题解读不能沿用上一问题的AI缓存。
5. **同一事复问与同辰同盘分开处理。** 不同问题同辰的提示可以继续；相同问题无新变化应回到旧记录。文本相等检查只能发现明确重复，不能吹嘘已识别所有同义改写。模型分类也不作为排盘随机源。
6. **年命是辅助，不伪造输入。** 保留现有手填本命／行年；未填就不使用相关断法。若实现自动行年，需要明示传统顺逆起法、虚岁、换年边界；出生公历年份不足以无歧义判断春节／立春附近的本命。可以保留手动校正，不静默从称谓猜性别或年龄。
7. **静态站点的实际范围。** GitHub Pages可以发布页面；无账号和后端时，本机历史、防复问记录、年命和个人设置不自动跨设备同步。网址跨设备可打开，不等于历史自动同步，也不等于程序能禁止朋友在另一台设备重复问同一事。

## 五、详细解读的真实性标准

一份有用的解读应分别展示：本次究竟问什么、已知与未知现实条件、采用哪种起课方式、可复核的课盘事实、本事项实际适用的已核传统依据、不能下结论的部分、可执行的现实核查步骤。多给套话或固定吉凶词不能弥补依据缺失。

- 程序计算的日辰、课、传、六亲、天将、旬空可作为“盘面事实”；不得写成现实中已经发生的事实。
- 已满足条件且与事项相关的已核条文才进入“传统解释”；九宗门取传口诀只能说明怎么排出三传，不能直接证明事情吉凶。
- 将传统象义对应到考试、订单、关系等现代场景时写明是推测，不虚构对方心理、合同进度、付款承诺或确切应期。
- 证据覆盖不足时照实写“目前已核材料不足以判断此项”；可以列出本问题最值得调查的变量，但不能假扮有古籍背书。
- 不给虚构的成功概率、确定日期、财务回报、疾病诊断、危险方位或失踪人员坐标；现实中的紧急事项应依据现实信息处理。
- 没有接通模型或上游拒绝时，清楚显示本地结构分析与错误状态，不以预置长答案充当一次真实AI解读。

## 六、建议验证情形

以下是本功能的验收建议，不表示本文已经运行这些测试：

- 同一真实瞬间报1和报12：日干支、月将、月建、真实时间与昼夜口径保持；占时分别为子、亥。
- 同一瞬间同一数字复现：结果确定；数字0、13、小数、空值不可进入排盘。
- 实际23:00前后的日界与报数子时互不混淆；中气前后的月将以真实瞬间转换。
- 原盘续问第二事项：原盘ID、天地盘、四课三传、天将和原起课时间完全相同，新问题和解读独立。
- 补年命仅改变辅助事实；不因生年变化而改写四课三传。
- 同一无变化事项不能靠更换正时／活时／续问入口绕过本机复问约定；存在新情况时保留关联与变化说明。
- 两个新问题同盘时能继续，并分别给出相关的现实问题分析；不为了区分而新增无依据的传统规则。

本文只新增来源研究说明。上述新扫描中的段落若将来进入正式自动判断，仍须完成对应底本说明、逐字转录、适用条件及反例测试，并更新正式证据清单；不能直接把本文当作全书已校证书。
